# Hazard 7007 — веб-версия

Это готовая браузерная версия приложения. Основной интерфейс и звуковые файлы находятся внутри `index.html`.

## Публикация
1. Загрузите все файлы и папки из этого набора на статический хостинг (например, Netlify, Cloudflare Pages или GitHub Pages).
2. Откройте выданный HTTPS-адрес на iPhone или Android.
3. На iPhone: Safari → «Поделиться» → «На экран Домой».
4. На Android: Chrome → меню ⋮ → «Установить приложение» или «Добавить на главный экран».

Для микрофона и установки PWA нужен HTTPS. Просто открыть `index.html` как локальный файл можно для проверки интерфейса, но микрофон и офлайн-установка могут не работать.
